# مين الأذكى؟ — مشروع أندرويد

## بناء APK من الموبايل فقط
1. فك ضغط الملف وارفع **كل محتوياته** إلى مستودع GitHub جديد في الفرع main، وليس ملف ZIP نفسه.
2. افتح Actions وشغّل Build Min Alazka APK.
3. افتح آخر عملية ناجحة وانزل إلى Artifacts.
4. حمّل Min-Alazka-APK، فك ضغطه، وثبّت app-debug.apk.

## الموجود في النسخة الأولية
- تطبيق أندرويد مستقل.
- لعب محلي على نفس الهاتف للاعبين أو أكثر.
- أسئلة عربية متنوعة، مؤقت، نقاط، ترتيب وفائز.

## الأونلاين وFirebase
واجهة إعداد الغرف موجودة، لكن الاتصال الحقيقي بين الأجهزة يحتاج إعداد Firebase Realtime Database وإضافة Firebase Web SDK وإعدادات مشروعك داخل index.html. في هذه النسخة الأولية، إنشاء/الانضمام ومزامنة أسماء اللاعبين هيكل تمهيدي فقط؛ جولات الأسئلة والإجابات المتزامنة تحتاج استكمالًا قبل اعتبار اللعب الأونلاين مكتملًا.

## الإعلانات والنشر
AdMob غير مفعّل بعد. يُضاف بعد اختبار اللعبة، باستخدام معرّفات إعلانية تجريبية أثناء التطوير. هذه نسخة أولية للاختبار وليست إصدارًا نهائيًا للنشر.
